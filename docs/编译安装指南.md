# WPE x64 编译与安装指南

> 本项目为 **C# + WPF（.NET Framework 4.8）** 桌面软件，**只能在 Windows x64 上编译与运行**。
> 主程序 UI 在 `src/Wpe.App`，原生拦截内核在 `src/Wpe.Core`，统一解决方案为 `src/WPE.sln`。

---

## 一、环境要求

| 组件 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11 x64（或 Windows Server x64） |
| 运行库 | .NET Framework **4.8**（运行必需） |
| 编译器 | Visual Studio **2022**（含「.NET 桌面开发」工作负载）或 Build Tools for VS 2022 |
| 目标框架包 | .NET Framework 4.8 **Developer Pack / Targeting Pack**（编译必需） |
| 依赖还原 | NuGet（VS 内置，联网即可自动还原 EasyHook、EntityFramework 6、SQLite、OWIN 等） |

> 提示：软件涉及 Winsock 钩子与进程注入，安装/运行时请以 **管理员身份** 启动，并对杀毒/安全软件添加信任。

---

## 二、获取源码

方式 A — Git 克隆（推荐）：

```bash
git clone https://github.com/GQBA7010/zhuruqi.git
cd zhuruqi
git checkout zhuruqi
```

方式 B — 直接下载源码压缩包：

- https://github.com/GQBA7010/zhuruqi/archive/refs/heads/zhuruqi.zip

下载后解压，进入解压目录即可。

---

## 三、编译

### 方式 A：Visual Studio 2022（图形界面，最简单）

1. 双击打开 `src/WPE.sln`。
2. 顶部工具栏将解决方案平台切换为 **x64**，配置选择 **Release**（或 Debug）。
3. 首次打开会自动还原 NuGet 包（需联网）；若未自动还原，右键解决方案 → **还原 NuGet 包**。
4. 菜单 **生成 → 生成解决方案**（快捷键 `Ctrl+Shift+B`）。
5. 生成成功后，可执行文件位于：
   `src/Wpe.App/bin/x64/Release/`（或对应 Debug 目录）下的 `Wpe.App.exe`。

### 方式 B：命令行（MSBuild）

```powershell
# 打开「Developer PowerShell for VS 2022」
cd zhuruqi

# 还原依赖
msbuild src\WPE.sln /t:Restore

# 编译（Release / x64）
msbuild src\WPE.sln /p:Configuration=Release /p:Platform=x64
```

> 也可使用 `dotnet build src/WPE.sln -c Release`（需本机安装含 MSBuild 的 .NET SDK 与 4.8 Targeting Pack）。

---

## 四、运行 / 安装

1. 进入生成目录 `src/Wpe.App/bin/x64/Release/`。
2. **右键 `Wpe.App.exe` → 以管理员身份运行**（钩子/注入需要管理员权限）。
3. 首次运行会在本地生成配置与 SQLite 数据库；关闭软件时配置自动保存，下次自动带出。
4. 如需分发，把整个 `Release` 目录一起拷贝（包含所有 DLL 与 `x86/x64` 原生动态库），确保目标机已安装 **.NET Framework 4.8**。

---

## 五、两种拦截模式

- **进程注入模式**：在「进程注入」页选择目标进程注入后开始捕获封包；注入模式下的封包编辑器运行于目标进程内部（沿用原生 WinForms，保证 1:1）。
- **SOCKS 代理模式**：在「SOCKS 代理」页配置监听端口/认证并启动，客户端走代理即可捕获，配合「端口映射」「代理账号」使用。

## 六、常见问题

| 现象 | 处理 |
| --- | --- |
| 编译报缺少 .NET Framework 4.8 | 安装 4.8 Developer Pack / Targeting Pack 后重开 VS |
| NuGet 还原失败 | 检查网络/代理，或手动执行 `msbuild /t:Restore` |
| 注入无效 / 无封包 | 以管理员身份运行；确认目标进程位数与自动选择的 32/64 位 DLL 一致 |
| 被安全软件拦截 | 对程序目录添加信任/白名单（钩子行为易被误报） |
| 运行提示缺少组件 | 目标机安装 .NET Framework 4.8 运行库 |
